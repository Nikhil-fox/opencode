Add an additional working directory to this session so all tools can access files within it.

Usage: /add-dir <path>

The path can be:
- An absolute path: /home/user/projects/my-app
- A path relative to the current directory: ../other-project
- A home directory path: ~/projects/my-app

Files in the added directory become accessible to all tools (read, write, edit, grep, glob, etc.) for the duration of this session.
