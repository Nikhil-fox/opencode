Add an additional working directory to the current session.

Usage: /add-dir <path>

This will:
1. Validate the path exists and is a directory
2. Add it to the session's allowed directories
3. Allow all tools (read, edit, glob, grep, bash) to access files in this directory
4. Include the directory in the AI's context

The directory access is session-scoped only and will not persist across sessions.

Arguments:
  $1 - Absolute path to the directory to add

Example:
  /add-dir /home/user/projects/shared-lib
